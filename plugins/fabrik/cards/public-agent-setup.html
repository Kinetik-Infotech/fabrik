Public agent

The chat box on your website answers visitors from KNOWLEDGE.md alone. Anthropic charges your business's API key for each answer. Type the keys here, not in the chat.

Anthropic API key

  1. On a Claude Max, Ultra or Team plan, claim its API credits on claude.ai in Settings, then Billing, with Link organization. Otherwise buy credits in the Claude Console under Billing.
  2. Open the Claude Console at platform.claude.com and start a new API key.
  3. Where it asks "Where does your code run?", choose Somewhere else.
  4. Name it fabrik website, create it and copy it. It starts sk-ant-, and the Console shows it only once.

Turnstile keys

  1. Open dash.cloudflare.com/?to=/:account/turnstile and sign in. A free Cloudflare account is enough.
  2. Choose Add widget manually, not Set up with Spin.
  3. For Widget name type fabrik chat. Under Hostname management add your chat page's address, which Claude gave you, without https://. Leave Widget mode at Managed.
  4. Choose Create. Cloudflare shows a site key and a secret key. Copy each into its box below.
