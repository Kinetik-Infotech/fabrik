# Projects and tasks

A project is work with several steps, such as a client job, a launch or a renovation. Each step is a task.

## A project

Say "Let's run a project on the kitchen renovation". Claude asks what done looks like and the date it is due. It saves the project with its tasks, and which tasks wait on others.

## Tasks

A task has a state: pending, in progress, paused, completed or cancelled. It can have a due date, a priority and the deliverables that finish it. A task can wait on others, and fabrik refuses to complete it before them.

Ask "What can I do next?" for the tasks no other task holds up. Ask "What is due this week?" for your tasks by date. Tell Claude when a task is done, and it marks it completed.

## The board

Ask for the project's board. Claude shows its tasks in columns by state, with their dates and what is overdue. In a Code session it can also draw the board as a page in your folder.

## Finishing

Claude completes the project once its tasks are done, and lists any still open. Ask for a retrospective, and Claude writes down what went well and what to change.

A task can also stand alone, outside any project, in General.
